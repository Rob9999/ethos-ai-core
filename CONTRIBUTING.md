# Contributing to EthosAI Core Concepts

Danke für Ihr Interesse! Beiträge zu den Konzeptdokumenten
sind herzlich willkommen.

## Beitragsregeln

1. **CLA erforderlich** — Alle Beiträge unterliegen unserem
   [Contributor License Agreement](.github/CLA.md). Beim ersten
   PR werden Sie automatisch zur Unterzeichnung aufgefordert.

2. **CC-BY 4.0** — Alle eingereichten Inhalte werden unter
   CC-BY 4.0 veröffentlicht.

3. **Konzeptebene** — Dieses Repository enthält nur Konzepte,
   keine Implementierungen. Code-Beispiele sind nur als
   Pseudocode erlaubt.

4. **Markenrecht** — Verwenden Sie „EthosAI™" mit dem
   Trademark-Symbol bei der ersten Erwähnung.

## Pull Requests

1. Forken Sie das Repository
2. Erstellen Sie einen Feature-Branch
3. Schreiben / überarbeiten Sie ein Konzeptdokument
4. Stellen Sie sicher, dass keine internen Details enthalten sind
5. Erstellen Sie einen PR mit aussagekräftiger Beschreibung

## Qualitätsstandards

- Dokumente in Deutsch oder Englisch
- Markdown-Format mit korrektem SPDX-Header
- Mermaid-Diagramme für visuelle Erklärungen
- Quellenangaben wo angemessen

## Kontakt

Bei Fragen: Issues im Repository erstellen.
