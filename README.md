## Überblick

Dieses Repository enthält die öffentlichen **Konzeptdokumente** des
EthosAI™-Projekts — ein Framework für KI-Systeme, die ethische
Prinzipien, Bewusstseinssimulation und EU-Compliance als
integrierten Bestandteil implementieren.

Der Public Scope ist bewusst kuratiert: Dieses Repository veröffentlicht
Grundlagen, Begriffe und Architekturprinzipien. Interne Runtime-Details,
Kundenauslieferungsmodelle, Sicherheitsimplementierungen und kommerzielle
Produkt-Roadmaps gehören nicht in diesen Mirror.

### Warum Open Source?

- **Transparenz** — Konzepte sollen überprüfbar und diskutierbar sein
- **Akademische Zusammenarbeit** — Forscher können aufbauen und zitieren
- **Vertrauen** — Offene Prinzipien zeigen ethische Ernsthaftigkeit
- **Community** — Beiträge sind willkommen (unter CLA)
